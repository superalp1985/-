# 《王大粘因子拆解》电子书怎么用

前面 8 章、44 篇因子文章写完后，我把它们合成了 PDF，名字叫《王大粘因子拆解》。网盘里那个名为 `stock` 的文件就是它。

先说清楚，它不是另起炉灶重写的一套内容，也不是“看完就能拿去跑策略”的东西。正文还是原来的文章。合订本重新处理的，是目录、索引、页码、跨章链接、PDF 书签，以及手算图和 DAG 截图的位置。

![《王大粘因子拆解》电子书封面](https://raw.githubusercontent.com/superalp1985/-/main/articles/%E7%9F%A5%E4%B9%8E%E4%B8%93%E6%A0%8F/images/ebook-cover.png)

这件事对零散阅读的人和我自己都更方便。以前要查 KMID，只能在目录里翻文件；现在可以直接从总目录跳过去，也可以用 PDF 阅读器搜索因子名。

## 里面到底装了什么

全书覆盖 8 章、44 篇文章和 88 张文章配图。Alpha158 的 5、10、20、30、60 日窗口，合并在同一个因子家族里讲；Alpha360 的 60 个历史位置也没有拆成 60 篇重复文章。

每篇正文基本围绕同一组问题展开：

- 它到底在算什么；
- 为什么有人会这样设计；
- 它在哪些情况下容易失效；
- 放到因子工坊里，节点应该怎样拆；
- 改一个输入、参数或操作，结果为什么会变。

文章里有两类图。第一类是手算图，用较短窗口把中间过程写出来；第二类是项目里的真实 DAG 截图，通常使用 20 日版本。手算图和真实截图分开，是怕读者把“方便讲解的小例子”误当成项目默认参数。

![电子书总目录与章节索引](https://raw.githubusercontent.com/superalp1985/-/main/articles/%E7%9F%A5%E4%B9%8E%E4%B8%93%E6%A0%8F/images/ebook-contents.png)

## 它解决的其实不是“背公式”

刚开始看因子时，最容易卡住的地方不是计算本身，而是公式和现实问题对不上。

比如 KMID 看着像日涨跌幅，实际却是今天开盘到今天收盘；ROC 在 Qlib Alpha158 里也不是常见的 `Close / Ref(Close, n) - 1`，而是历史价格除以当前价格的比值。BETA 对的是时间编号，不是大盘收益率。QTLU、QTLD 用的是收盘价分位数，不是最高价和最低价。

这些地方只在软件里点一下，很容易以为自己懂了。写成一篇文章，就能把手算数据、源码口径和画布节点放在一起核对。

电子书把 Qlib 定义固定到了提交 `be725493eb1a6bbb42bf11b37aa7669f59610ff1`。正文里涉及字段名、滚动窗口、缺失值和常数边界的部分，都尽量给出对应的源码位置。这样以后 Qlib 主分支发生变化，也能知道文章究竟核对了哪一个版本。

## 怎么和“王大粘 · 因子工坊”配合用

文章负责把一个问题讲清楚，画布负责把表达式拆成积木。两边单独看都能用，但合起来更顺。

![王大粘 · 因子工坊总览](https://raw.githubusercontent.com/superalp1985/-/main/articles/%E7%9F%A5%E4%B9%8E%E4%B8%93%E6%A0%8F/images/factor-canvas-overview.png)

因子工坊不是只用来展示文章里的 DAG。它可以搜索因子库、拆节点、改参数、导入自己的数据跑检查，再把结果导出成不依赖项目运行时的 Python 或数学表达式。文章告诉你字段和数学口径，项目负责让你把表达式真正搭出来。

我的建议是不要一上来就在画布里随便连线。比较稳妥的顺序是这样：

1. 先在文章里找到因子定义和手算例子，确认它回答的是价格、成交量还是时序关系。
2. 再到因子工坊里搜索同名因子，展开 DAG，看每个节点的输入、参数和连线方向。
3. 拿文章里的短窗口数据，对照图中每一步的结果。哪里对不上，先检查字段和参数，不要急着改公式。
4. 确认自己看懂以后，只改一个地方，观察输出怎么变。最后再导出 Python 或数学表达式，带回自己的环境做检查。

画布里的节点不是装饰。字段、窗口、最少有效样本、分母和很小的常数，都会影响结果。DAG 截图的作用也不是“证明这个因子很高级”，而是让你知道公式里到底做了哪些动作。

## 初学者可以从哪几篇开始

不用从第一页硬啃到最后一页，也不建议一开始就背 44 个名字。

先看第一章和第二章，挑一两个能手算的因子。第一章的 K 线结构来自同一根示例 K 线，第二章则把一根 K 线扩展成一段窗口。两章读完后，价格字段、窗口和归一化会清楚很多。

![KMID 手算示例](https://raw.githubusercontent.com/superalp1985/-/main/articles/%E7%9F%A5%E4%B9%8E%E4%B8%93%E6%A0%8F/%E7%AC%AC%E4%B8%80%E7%AB%A0-K%E7%BA%BF%E7%BB%93%E6%9E%84%E5%9B%A0%E5%AD%90/images/01-kmid-example.png)

看手算图时，可以拿纸把数字盖住，自己先算一遍。算完再对照正文，通常比只看结果更容易发现口径问题。

然后看第四章和第五章，理解“次数”和“幅度”不是同一个东西，价格变化和成交量变化也不是同一个东西。第六章讲相关，第三章讲趋势、分位和极值位置，可以放在前后价格与成交量框架建立之后再读。

第七章和第八章主要对应 Alpha360 和字段序列。它们放到最后读，前面已经有字段、窗口和 DAG 的基础，不容易把“某一天的字段引用”误读成“整段区间的统计”。

## 有经验的人可以把它当工具书

如果已经熟悉 pandas、Qlib 或自己的因子框架，这本电子书更适合当核对手册，而不是从头读到尾。

用得最多的通常有三个入口：

1. 从 PDF 书签直接跳到因子家族；
2. 搜索因子代码，快速核对公式和字段；
3. 看“失效条件”“数据边界”和源码来源，再决定代码里要不要补缺失值、样本门槛或数据清洗。

![KMID 在因子工坊中的 DAG](https://raw.githubusercontent.com/superalp1985/-/main/articles/%E7%9F%A5%E4%B9%8E%E4%B8%93%E6%A0%8F/%E7%AC%AC%E4%B8%80%E7%AB%A0-K%E7%BA%BF%E7%BB%93%E6%9E%84%E5%9B%A0%E5%AD%90/images/01-kmid-dag.png)

这种做法省掉的是低级返工。比如把 `Max($high, n)` 写成 `Max($close, n)`，把样本标准差写成总体标准差，或者把 `1e-12` 直接省略成 0。公式看上去只差一点，输出和缺失边界却会变。

## 它不负责什么

电子书不提供买卖点，不评价某个因子以后会不会有效，也不替你完成样本外检验、交易成本、涨跌停、停牌和实际执行检查。

它做的是另一件事：把一个因子的数学定义、设计动机、失效条件和画布实现摆在一起，让你在写代码之前先知道自己在算什么。

这对研究是基础工作，不是收益承诺。

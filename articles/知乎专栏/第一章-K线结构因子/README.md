# 第一章：K 线结构因子

这一章只用四个字段：开盘价、最高价、最低价、收盘价。

为了方便比较，九篇文章都使用同一根示例 K 线：

```text
Open  = 10.00
High  = 10.80
Low   =  9.60
Close = 10.50
```

同一组数据换一种计算方法，看到的市场特征就会不同。这样比每篇换一只股票、换一组数字更容易把公式之间的关系看清楚。

## 这一章想说明什么

K 线结构因子不会直接告诉我们“下一步一定涨还是跌”。它们首先是在描述当天发生了什么：

- 实体有多长；
- 全天振幅有多大；
- 上下影线各占多少；
- 收盘落在当天区间的什么位置。

真正做研究时，还要把这些描述和历史窗口、股票横截面、成交量、市场状态以及未来标签放在一起检验。

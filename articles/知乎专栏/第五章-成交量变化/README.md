# 第五章：成交量变化

这一章分清三个问题：今天的量相对近期是什么水平，量或量价变化乘积有多不均匀，放量与缩量各贡献了多少变化幅度。六个家族各写一篇，窗口参数不重复成文。手算统一用五日，画布节点拆解统一用二十日。

## 共同样本

| 交易日 | 收盘价 Close | 成交量 Volume | 相邻成交量差 d |
| --- | ---: | ---: | ---: |
| 第 0 天，前值基准 | 10.0 | 100 | 不计入窗口 |
| 第 1 天 | 10.4 | 120 | 20 |
| 第 2 天 | 10.2 | 90 | -30 |
| 第 3 天 | 10.2 | 90 | 0 |
| 第 4 天 | 10.8 | 150 | 60 |
| 第 5 天，今天 | 10.6 | 130 | -20 |

成交量使用同一单位，价格采用一致口径。VMA、VSTD 只用第 1 至第 5 天的五个量。WVMA 用六个收盘价构造五个 `z`，再乘各自当天的量；第 0 天的量不参与乘积。三个 VSUM 用六个量构造五次变化，不可漏掉基准行。

定义 `e=1e-12`、`d=Volume-Ref(Volume,1)`、`z=Abs(Close/Ref(Close,1)-1)*Volume`，以下是 `src/factors.ts` 原式的等价简写：

| 家族 | n 日表达式 | 五日样本结果 |
| --- | --- | ---: |
| VMA | `Mean(Volume,n)/(Volume+e)` | 0.8923076923 |
| VSTD | `Std(Volume,n)/(Volume+e)` | 0.2005908432 |
| WVMA | `Std(z,n)/(Mean(z,n)+e)` | 0.9607328351 |
| VSUMP | `Sum(max(d,0),n)/(Sum(Abs(d),n)+e)` | 约 8/13，即 0.6153846154 |
| VSUMN | `Sum(max(-d,0),n)/(Sum(Abs(d),n)+e)` | 约 5/13，即 0.3846153846 |
| VSUMD | `(Sum(max(d,0),n)-Sum(max(-d,0),n))/(Sum(Abs(d),n)+e)` | 约 3/13，即 0.2307692308 |

所有计算由 Python 从原始输入完成，显示时才舍入。五日量均值为 `116`，样本方差为 `680`，样本标准差约为 `26.0768096208`。五个 `z` 依次约为 `4.8、1.7307692308、0、8.8235294118、2.4074074074`，均值约 `3.5523412100`，样本标准差约 `3.4128508418`。不要拿已舍入的展示值重新统计。

## 必须分清的口径

- `Greater(x,0)` 是 `maximum`，保留正数的数量大小，不是布尔“大于零”。VSUMP、VSUMN 累计原始成交量差，不统计天数，也不累计百分比变化。
- `Std` 采用样本标准差 `ddof=1`；只有一个有效观测时未定义，不能当零。WVMA 是变量 `z` 的变异系数，不是加权移动平均价。
- 在有效价格、非负成交量下，`z` 均值为零意味着全部有效 `z` 为零；满足最少样本要求且至少两点时，WVMA 为零。前收盘为零或缺失则须先处理无效收益率。
- 本例放量幅度 `80`、缩量幅度 `50`、总绝对量变 `130`。同窗两项比例之和是 `130/(130+e)`，约 `0.9999999999999923`，不是严格一。全窗量持平时三个 VSUM 全为零。
- VMA 当前量为零时，历史均量若为正，会得到很大有限值，不保证缺失。极小项防止原式分母为零，不负责识别停牌或坏数据。
- 单位必须全窗一致。固定极小项不随成交量缩放，近零时不能声称严格尺度不变。成交量不提供主动买卖方向，这些因子都不能直接解释成资金流向或买卖失衡。

## 画布复现

本章按现有节点名称拆解 `VMA20、VSTD20、WVMA20、VSUMP20、VSUMN20、VSUMD20`。手算时将所有相关滚动窗口同步改为 `5`；历史引用仍为 `1`。涉及差分或收益率的五日样本必须保留第零天。

实际展开中，`Greater(x,0)` 对应“逐行取大”，右值连接数字常数 `0`。VSUMP、VSUMN 各有一处，VSUMD 有两处；不能替换为布尔“大于”。WVMA 的均值与标准差各自拥有一套相同的 `z` 子树，核对时两处窗口须一致。

从因子库展开的本章滚动节点使用 `min_samples=1`，与固定版 Qlib 的 `min_periods=1` 对齐；样本标准差仍至少需要两点。手动新建滚动节点的默认门槛为 `5`，不要混淆这两种入口。复核五期手算只改窗口，保留门槛 `1`；本文样本完整、无缺失，并提供历史引用所需前值。若主动把门槛设为窗口长度，就是要求满窗，会改变 Qlib 默认的预热和部分缺失输出，不能再宣称这些边界完全一致。

均值、求和和标准差会跳过缺失输入，全窗缺失时为空；求和的空值不等于真实零变化。另搭放量次数变体时，比较结果先接 `fill_missing(0)` 再求均值，只将缺失比较按假计入，不把缺失成交量补零。

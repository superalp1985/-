# 王大粘因子拆解

> 不背公式，不迷信名字。把一个因子拆开，看它究竟算了什么、为什么有人这样算，以及什么时候别太信它。

![王大粘因子工坊总览](images/factor-canvas-overview.png)

这个专栏配合“王大粘 · 因子工坊”一起使用。

文章负责把问题讲清楚，软件负责把公式拆成积木、导入数据、运行检查，再把结果导出到用户自己的量化环境。

每篇讨论一个因子或字段家族，不为每个窗口、滞后参数重复写文章，并回答五个问题：

1. 它到底在算什么？
2. 为什么有人会这样设计？
3. 它在什么情况下容易失效？
4. 在画布里怎样拆成积木？
5. 改一个输入或操作，结果为什么会变？

这里讲的是研究工具，不是荐股，也不会把一个历史表达式包装成必然有效的策略。

## 来源与复现

源码核对日期：2026-09-27。定义与算子固定到 Microsoft Qlib 提交 `be725493eb1a6bbb42bf11b37aa7669f59610ff1`：

- [特征表达式与默认配置：loader.py](https://github.com/microsoft/qlib/blob/be725493eb1a6bbb42bf11b37aa7669f59610ff1/qlib/contrib/data/loader.py)
- [比较、历史引用及滚动算子：ops.py](https://github.com/microsoft/qlib/blob/be725493eb1a6bbb42bf11b37aa7669f59610ff1/qlib/data/ops.py)

复现时不能只核对公式名字：

- Qlib 导入的滚动节点使用 `min_samples=1`，对应源码的 `min_periods=1`。通用滚动积木默认门槛为 `5`；改成窗口长度是主动要求满窗，改变了预热和缺失时的输出条件，不是原版默认。
- CNTP、CNTN、CNTD 在比较之后接 `fill_missing(0)`，匹配 Qlib 缺失价格参与大小比较时为假的语义。填的是比较结果，不是把缺失价格补成零；计数均值非空也不证明价格齐全。
- Qlib 相关性节点（CORR、CORD）与趋势拟合度节点（RSQR）显式使用 `std_tolerance=2e-5`，通用积木默认 `0`。[Corr](https://github.com/microsoft/qlib/blob/be725493eb1a6bbb42bf11b37aa7669f59610ff1/qlib/data/ops.py#L1488-L1498) 检查两侧各自窗口的样本标准差，[Rsquare](https://github.com/microsoft/qlib/blob/be725493eb1a6bbb42bf11b37aa7669f59610ff1/qlib/data/ops.py#L1268-L1283) 检查输入序列的样本标准差；近零时置空，不能用通用默认冒充 Qlib 口径。
- Alpha158 官方价格名 `OPEN0/HIGH0/LOW0/VWAP0` 对应工坊的 `OPEN/HIGH/LOW/VWAP` 别名。Alpha360 的零滞后直接读字段，不写 `Ref(field,0)`；固定版 Qlib 的零参数引用取加载序列首值。
- 文章覆盖定义、手算与画布复现，不替代样本外检验、交易成本建模和实际执行验证。所有日终字段都须等数据可用后再使用。

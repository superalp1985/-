# 第四章：涨跌次数与幅度

涨得次数多，和上涨时走得远，不是同一件事。本章把 Qlib Alpha158 的六个家族分成两组：前三篇数上涨、下跌的次数，后三篇计算正负价差的总量及其占比。

每个家族一篇，`5、10、20、30、60` 只表示窗口参数，不重复写文章。手算统一采用五期变化；画布配图统一采用对应的 20 期因子。

## 六行价格，五次变化

| 观测日 | 收盘价 | 当前收盘减前收盘 | 上涨标记 | 下跌标记 |
| --- | ---: | ---: | ---: | ---: |
| 第 0 天，只补前值 | 10.00 | 不计入 | 不计入 | 不计入 |
| 第 1 天 | 10.40 | +0.40 | 1 | 0 |
| 第 2 天 | 10.20 | -0.20 | 0 | 1 |
| 第 3 天 | 10.20 | 0 | 0 | 0 |
| 第 4 天 | 10.80 | +0.60 | 1 | 0 |
| 第 5 天，今天 | 10.60 | -0.20 | 0 | 1 |

窗口统计的是第 1 至第 5 天的变化。计算第 1 天的变化还要取第 0 天，所以不能只给五行收盘价。这里的“天”指按交易日对齐后的观测位置，不是自然日位移。

上涨两次、下跌两次、平盘一次；上涨总量 `P=1.00`，下跌幅度总量 `N=0.40`，绝对变化总量 `A=P+N=1.40`。

## 两种统计，六个结果

下表用 `d=$close-Ref($close,1)` 简写单期价差。`P`、`N`、`A` 都在同一个窗口内求和；各篇保留完整的 Qlib 原始表达式。

| 家族 | 统计口径 | 本章五期结果 | 最容易误读的地方 |
| --- | --- | --- | --- |
| CNTP | `Mean(d>0,n)` | `2/5=0.40` | 上涨频率，不是未来上涨概率 |
| CNTN | `Mean(d<0,n)` | `2/5=0.40` | 平盘不算下跌，不能拿 `1-CNTP` 代替 |
| CNTD | `Mean(d>0,n)-Mean(d<0,n)` | `0` | 次数打平，不代表端点价格没涨 |
| SUMP | `P/(A+1e-12)`，`P=Sum(max(d,0),n)` | 约 `5/7`，即 `0.714286` | 计量价差，不是上涨天数 |
| SUMN | `N/(A+1e-12)`，`N=Sum(max(-d,0),n)` | 约 `2/7`，即 `0.285714` | 下跌幅度为正数，不是亏损率 |
| SUMD | `(P-N)/(A+1e-12)` | 约 `3/7`，即 `0.428571` | 不是收益率求和，也不是 Wilder RSI |

本例次数打平，但上涨总量更大。这就是 CNTD 为 0、SUMD 却为正的原因。完整、连续且无缺失时，`P-N` 可以逐项抵消成窗口末端收盘减窗口前一期收盘；分母仍保留中间往返的价差。

## 先检查这些边界

- **取大不是比较。** Qlib 的 `Greater(x,0)` 实际调用 `np.maximum(x,0)`，保留正价差幅度。它不同于计数因子里的严格 `>`；写错会把幅度偷换成次数。
- **平盘与缺失不能混同。** 收盘相等时，大于、小于都为假。上游价格为 `NaN` 时，这两种比较也为假；进入计数均值后按 0 计入，仍占分母，不是自动剔除。
- **均值和求和都允许短历史。** 官方滚动实现使用 `min_periods=1`。计数分母是已有比较结果的数量；幅度求和跳过 `NaN`，全缺失窗口为空值。非空输出不代表完整窗口已就绪。
- **epsilon 必须保留。** `SUMP+SUMN=A/(A+1e-12)`，通常近似 1，不是严格恒等于 1。完整全平盘时，SUMP、SUMN、SUMD 都为 0，不是未定义，也不等于全缺失。
- **价格与时点要对齐。** 各支使用同一标的、同源且同复权口径的收盘序列。今天最终收盘可用后才能计算完整读数，不能据此假设在更早时刻已获得信号。

## 配图与画布

每篇引用两张图：`images/序号-家族-example.png` 为六行数据的手算图，`images/序号-家族-dag.png` 为因子工坊相应 20 期因子的实际 DAG。序号从 `01` 到 `06`，文件中的家族名全部小写。

手算窗口 5 与 DAG 窗口 20 不混用。复核手算时改的是时序均值或求和窗口，历史引用仍为 1；改动多个分支时须一起调整。

官方表达式使用 `$close`、`Mean`、`Sum`、`Greater`，画布采用 `Close`、`Ts_Mean`、`Ts_Sum`、`Maximum` 等名称。比较计算结构、输入顺序和参数，不要求文本逐字相同。三篇幅度因子的逐行取大节点都必须接入常数 0，分母都保留 `1e-12`。

三篇计数因子在每条比较分支之后接 `fill_missing(0)`，再做均值。这是把缺失比较结果按假计入，以匹配 Qlib；不能在比较前把缺失价格补零。导入的均值与求和节点均为 `min_samples=1`，复核五期手算时只改窗口，保留此前值与缺失处理。

通用积木没有独立的 `>=`、`<=`。需要把平盘纳入计数时，用“大于或小于”与“等于”分别比较，再接“或者”（逻辑或）。手动搭建时，用“条件选择”（真值 `1`、假值 `0`）将组合条件转为数值序列，再接 `fill_missing(0)` 和均值，保持布尔、数值端口匹配。不要把填充后的数值直接接逻辑或，也不要用未经支持的积木名称代替实际连线。

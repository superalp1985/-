# 第二章：历史窗口因子

第一章只拆一根 K 线。这一章开始往回看：把今天和过去一段时间放在一起，观察价格的中心、波动、位置和趋势。

Qlib Alpha158 为这些因子准备了 `5、10、20、30、60` 五组窗口。公式没有变，变的只是向后看多少个观测。为了不把同一件事重复五遍，本章每个因子家族只写一篇：

- 手算统一用 5 个交易日，数字少，能看清每一步；
- 画布截图统一打开 20 日版本，例如 `MA20`、`RSQR20`；
- 实际研究时，再根据市场、频率和用途比较不同窗口。

## 本章示例数据

| 交易日 | 收盘价 | 最高价 | 最低价 |
| --- | ---: | ---: | ---: |
| 第 1 天 | 10.00 | 10.20 | 9.80 |
| 第 2 天 | 10.40 | 10.60 | 10.00 |
| 第 3 天 | 10.20 | 10.50 | 10.00 |
| 第 4 天 | 10.80 | 11.00 | 10.40 |
| 第 5 天 | 10.60 | 10.90 | 10.30 |

最后一天是“今天”。每篇文章都站在第 5 天收盘后，用这五天的数据计算。

## 先记住一件事

窗口因子不是把过去变成答案，只是把过去压缩成一个数字。

短窗口反应快，也更容易被偶然波动带着走；长窗口更平稳，但对新变化反应慢。到底用哪个窗口，不该靠名字决定，要放进自己的数据和研究流程里比较。

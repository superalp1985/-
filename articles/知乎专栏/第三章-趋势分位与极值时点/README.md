# 第三章：趋势、分位与极值时点

第二章看价格在窗口里的中心、波动和位置。这一章再问几件具体的事：过去价格相当于今天多少，价格沿时间走得多快，偏高和偏低的收盘价在哪里，高点和低点谁先出现。

七个因子家族，各写一篇。`5、10、20、30、60` 只是窗口参数，不另写重复文章。手算用短窗口，项目真实 DAG 统一展开 20 日版本。

除 ROC 外，五日窗口都只用第 1 至第 5 天，包含今天。ROC 的 `Ref(Close,5)` 是向前移 **5 个观测**，所以要额外取第 0 天，不能拿“五日窗口里最早一天”冒充。

## 先核对口径，再读名字

| 家族 | Qlib Alpha158 原式 | 容易读错的地方 |
| --- | --- | --- |
| ROC | `Ref($close,n)/$close` | 不是通常的 `Close/Ref(Close,n)-1` 收益率 |
| BETA | `Slope($close,n)/$close` | 对时间编号回归，不是对大盘收益率回归 |
| QTLU | `Quantile($close,n,0.8)/$close` | 收盘价的线性插值分位数，不是最高价 |
| QTLD | `Quantile($close,n,0.2)/$close` | 收盘价的线性插值分位数，不是最低价 |
| IMAX | `IdxMax($high,n)/n` | 最老观测编号为 1，并列最高取首次 |
| IMIN | `IdxMin($low,n)/n` | 最老观测编号为 1，并列最低取首次 |
| IMXD | `(IdxMax($high,n)-IdxMin($low,n))/n` | 正值是高点晚于低点，不是高点早于低点 |

**核对日期：2026-09-27。** 本章固定对照 Microsoft Qlib 提交 `be725493eb1a6bbb42bf11b37aa7669f59610ff1`，不靠一个随时会变化的 `main` 链接：

- [Alpha158 字段和表达式：loader.py](https://github.com/microsoft/qlib/blob/be725493eb1a6bbb42bf11b37aa7669f59610ff1/qlib/contrib/data/loader.py)
- [Ref、Quantile、IdxMax、IdxMin 的具体实现：ops.py](https://github.com/microsoft/qlib/blob/be725493eb1a6bbb42bf11b37aa7669f59610ff1/qlib/data/ops.py)
- [Slope 的回归与缺失值处理：rolling.pyx](https://github.com/microsoft/qlib/blob/be725493eb1a6bbb42bf11b37aa7669f59610ff1/qlib/data/_libs/rolling.pyx)

特别留意极值时点：`loader.py` 的英文注释容易让人读成“距今天多少天”，但 `ops.py` 实际计算 `argmax()+1` / `argmin()+1`。本章按可执行代码解释编号和正负号。

## 数据不完整时

本章手算都用完整、无缺失、同一复权口径的数据。工坊从因子库展开本章的斜率、分位数和极值位置积木时，最少有效样本设为 1，与所核对的 Qlib 默认预热口径一致；斜率仍至少需要两个有效点才能有定义。自己添加的积木保留原有默认值，研究时可以主动把最少有效样本改成完整窗口长度。

分位数跳过缺失值，斜率跳过缺失价格但保留日期间隔。极值位置不一样：Qlib 对原始窗口使用 NumPy `argmax/argmin`；混有 NaN 时可能选中缺失位置。本项目保留该行为以便复核，**它不代表那里真的有高点或低点**，应先检查、清洗数据。

样本不满窗口时，极值位置从已有窗口最老观测起编号，分母仍是参数 `n`。因此“越大越接近今天”的横向比较，以及 `1-IMAX`、`1-IMIN` 的距今天解释，都应先保证窗口完整。
